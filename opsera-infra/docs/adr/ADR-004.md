## Context

See ADR index for full rationale. Accepted during initial architecture design (WO-017).

## Decision

Use **Event Streaming — Kafka via Strimzi** for all applicable platform components.

## Alternatives Considered

See architecture document `docs/architecture/opsera-voyage-architecture.md` for full alternative analysis.

This decision is foundational — changing it would require significant refactoring across multiple services.

All platform compliance requirements (SOX, SOC 2, PCI-DSS, GDPR, DORA) were considered during selection. See related ADRs for detailed compliance impact.
